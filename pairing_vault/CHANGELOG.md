# Changelog

## 0.2.0

- Read a QR code from a photo (works over plain http) or, on https, live from the camera.
- Matter and Z-Wave SmartStart codes fill in the type and the manual pairing code or DSK, and show the vendor and product details they carry.
- Show a stored QR code full screen so it can be scanned again for re-setup.

## 0.1.0

- First version: store Matter and Z-Wave devices with their setup codes and serial numbers, and add, edit, search and delete them from the sidebar panel.
